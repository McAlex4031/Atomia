Conditions générales d'utilisation

Dernière mise à jour : 10 septembre 2026

Bienvenue sur ATOMIA ⚛️, un explorateur interactif de la matière destiné à permettre la découverte et la consultation d'informations scientifiques sur les éléments chimiques, les ions, les nucléides et leurs propriétés.

En utilisant ATOMIA, vous acceptez les présentes Conditions Générales d'Utilisation (CGU).

1. Présentation du service

ATOMIA est un projet gratuit à vocation principalement éducative et scientifique.

Le site permet notamment de consulter :

  • les 118 éléments chimiques ;
  • le tableau périodique ;
  • leurs propriétés physiques et chimiques ;
  • les ions ;
  • les nucléides et isotopes ;
  • des informations historiques ;
  • des utilisations et occurrences courantes ;
  • différentes informations scientifiques complémentaires.

ATOMIA peut évoluer, être modifié, complété ou interrompu à tout moment.

2. Gratuité

L'utilisation d'ATOMIA est gratuite.

Aucun abonnement, paiement ou achat n'est nécessaire pour accéder aux fonctionnalités proposées.

ATOMIA n'a pas pour objectif de vendre les données scientifiques présentées sur le site.

3. Sources et données scientifiques

Les informations présentées par ATOMIA proviennent exclusivement de sources et de bases de données accessibles gratuitement.

Les principales sources utilisées sont notamment :

  • NIST ;
  • IUPAC ;
  • NUBASE ;
  • ainsi que d'autres sources scientifiques publiques pouvant être utilisées pour compléter certaines informations.

La liste et les fichiers de données utilisés par le projet sont disponibles publiquement dans le dépôt GitHub officiel d'ATOMIA.

Cependant, aucune garantie absolue n'est donnée concernant l'exactitude, l'exhaustivité ou l'actualité de toutes les informations présentes sur le site.

Certaines propriétés peuvent être inconnues, estimées ou dépendre de conventions scientifiques particulières.

ATOMIA ne doit donc pas être considéré comme une source scientifique officielle ou comme un remplacement d'une publication scientifique, d'une base de données officielle ou d'un professionnel qualifié.
